### Added

- The memory graph is drawn with Sigma. You can zoom in, zoom out, and fit the graph to the view while nodes are laid out.
- On a phone, chats live in a drawer opened from the top left, with the ones that need you first. From the chat on screen you can rename it, move it to a project, archive it, or delete it, and attach photos from the composer. Another chat that needs you, or that finishes, shows a notice with a way to open it.
- Settings → Models & defaults can set a default model and thinking level per project. New chats in that project start there; the composer can still switch one conversation.
- Models in a provider can be reordered.
- Remote access can listen on the local network (Settings → Remote access → Allow LAN access). Devices on the same network open the address shown there; the remote-access password is still required.

### Improved

- Desktop notifications are one switch in Settings → General. Task finished, task failed, needs an answer, and app update all follow it. Turning it off silences every one. An older install that had switched off only one of those scenes is no longer stuck silent for that scene.
- A reply that hits the model's maximum output length says so, and points at Continue or raising Max output in the model details.
- A queued message that could not be sent says so, instead of only pausing the queue.
- A background chat whose run stops unexpectedly keeps a mark in the sidebar, and a notice names the chat with a way to open it.

### Fixed

- On macOS, reading Desktop, Documents, Downloads, iCloud, cloud storage, or an external volume no longer asks again for every file after you click Allow, and FastVibe no longer asks for Full Disk Access to cover those folders.
- Reopening a chat whose transcript had a gap no longer drops everything written before that gap. The missing link is repaired when the chat is opened.

### Build

- Installers are smaller. The macOS package no longer ships a duplicate ONNX library, and the computer-use helper ships only there. The Linux package no longer ships the computer-use library or the optional CUDA and TensorRT providers; memory still runs on CPU.
