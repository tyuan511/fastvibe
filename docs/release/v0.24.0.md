### Added

- **Phones now connect over iroh.** 设置 → 远程访问 is one switch over one transport: the computer registers its iroh endpoint with your account, and phones signed in to the same account reach it directly — no address, no LAN password, no QR code. The pane reports the endpoint identity, every connected device and whether each one took a direct path or the relay, and shows the relay allowance left on the account. This needs the FastVibe mobile app; the old WebRTC account connection and the LAN listener are no longer the product path.
- **Vivi, a desktop companion.** 设置 → 通用 → Vivi 桌面伴侣 puts a small 3D character on the desktop. She follows what your agents are doing — thinking, running tools, finishing, failing — and reacts when you drag, throw or catch her, with a speech bubble for short lines and a chat panel that sends prompts into the conversation she is watching. Size, opacity and palette (Sky, Grape, Mint, Peach, Cloud) are configurable; off by default.
- **Settings → 关于 → 引擎** chooses where the embedded engine keeps its configuration: FastVibe's own runtime (the default) or your global pi agent directory. Switching backs up the target, migrates providers, credentials, the default model, MCP servers and resource folders, then restarts. It refuses while a run, a parked prompt or a delegated agent is live, and the source directory is kept so switching back is not a rebuild. Conversations, queues, checkpoints and schedules never move. This replaces the old one-way 同步配置到全局 pi button.

### Improved

- **Delegation is a team, not a fan-out.** The `subagent` tool is gone; agents now create persistent threads with `spawn_agent`, post to them with `send_message` / `followup_task`, collect results with `wait_agent` and stop one with `interrupt_agent`. Threads live in the database and are driven by Main, so a delegated run survives a reload and can be steered from any client, and each thread gets a name and an avatar in the side pane. A thread keeps its history when it is interrupted, so a follow-up continues the same work.
- **The thinking picker is a slider.** Choosing a reasoning effort is one gesture along the model's own scale instead of a submenu of levels, and the current level is previewed as you drag.
- **Computer control got considerably more capable.** The agent can drag, move the cursor, read cursor position and state, resize windows, take a screenshot of a region, and check its own work with `computer_verify_state` — asserting a window's bounds or an element's value before it reports success. `computer_batch` returns per-step structured results so a sequence of actions reports what actually happened at each step.
- **Context can compact itself in the background.** 设置 → 偏好设置 → 对话 → 后台压缩上下文 (off by default) lets the app start a compaction once a turn has settled and the context is past 75%, so the next prompt is rebuilt from a fresh checkpoint instead of waiting for the summary. The 90% guard waits for that task and re-checks before forcing a second one; a failed background task never blocks a send, and progress, success and failure are reported as notifications.
- Auto archive offers **3 days** as its shortest window, for people who want finished work off the sidebar quickly.

### Removed

- **DAG task orchestration is gone.** The `dag_*` tools, the task graph, the scheduler and the 动态任务编排 setting were removed; delegation now goes through agent threads. Nothing else changes — an independent task was already using the plain delegation path.
