### Improved

- **Git changes are easier to find.** The file explorer now marks changed files and their parent folders, and the Git pane groups changes into a collapsible directory tree, including deleted files.
- **Search terminal output and open links.** Press Cmd+F or Ctrl+F to find text, use Enter or Shift+Enter to move between matches, and click HTTP or HTTPS links printed in the terminal.
- **Preview file changes from the conversation.** Hover over an edited file to see its diff. Each turn initially shows three files, with a control to expand the rest or collapse them again.
- **More context in sidebar hover cards.** Conversation cards show the full title, last activity, and working directory. Project cards also show total and running task counts, including pinned chats.

### Fixed

- **More reliable Git file status.** Unicode names, whitespace, rename destinations, and files inside untracked directories are preserved correctly. Projects opened at a repository subfolder now resolve status paths relative to that folder.
