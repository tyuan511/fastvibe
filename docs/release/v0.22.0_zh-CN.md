### 改进

- **FastVibe 自己的记录收进了一个数据库**，不再是十几个「每次改动就整份重写」的文件。能感觉到的差别：崩溃或被强杀不再让你失去文件回退这道保险——检查点在**捕获的那一刻**就落盘，所以「重试这一轮」照样会提出把文件放回去；v0.21.0 给对话列表加的「按行合并落盘」现在也覆盖了排队消息、任务图、定时任务、思考耗时和记忆账本；回答一个问题不再需要把全部内容扫一遍。
  - 本版本第一次启动会把旧文件转换进数据库，并在旁边留一份 `.migrated-<时间戳>`。对话转写仍是普通 JSONL，设置、供应商和 MCP 也照旧各自成文件——你的配置没有搬地方。
- **SSH 远程项目现在拿到了 v0.21.0 承诺过的能力。** 本版本带上 **Agent runtime v15** 的元数据，所以 Office 文档预览、文件面板的**新建文件** / **新建文件夹** / **重命名** / **删除**、以及 Git 变更对比，都能真正落到那台持有文件的机器上，不再回一句「方法不可用」。

### 修复

- **用了记忆的回复，末尾不再多出一个空代码块。** 这类回复会为记忆流程带上一段引用块，而模型照抄协议里的写法——协议示例本身就画在代码围栏里。以前只藏起了标签，围栏留下并画成了一个空框，于是每一条这样的回复末尾都多出一个没人要的方块；现在这层包装跟着一起删，正在写入、只有一半的引用块也一样处理。
- 侧边搜索不再命中这段内容。以前查一个对话 id，会从读者从来没被显示过的文字里跳出一条命中。
