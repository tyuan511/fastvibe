### Added

- **Long-term memory now maintains itself.** A daily pass runs while the app is idle: temporary memories that have gone unused are archived, exact duplicates collapse into one, and memories that have been replaced by a newer fact are retired. Preferences and standing rules are never archived automatically. Settings → Long-term memory turns maintenance off, sets the retention windows and the active-memory target, and can run a pass on demand.
- **Memories can be pinned, restored and inspected.** Any memory can be kept indefinitely, and an archived one shows why it left — expired, duplicate, superseded, merged or over capacity — with a link to the memory that replaced it. The memory graph gained a page control and an Active / Awaiting deletion filter, so a large index is browsable.
- **Glass.** Settings → Preferences → Appearance can draw the window over the macOS blur: every theme gets a translucent form, the sidebar, right pane and settings list float as rounded glass panes, and glass edges carry a specular rim. The option only appears where there is a blur to show, and Main follows the system's light/dark change without waiting for a theme edit.
- **A live header while a run is in flight.** A reply being streamed now carries an elapsed header ("Working for 1 minute 24 seconds") instead of the transcript going quiet between tool calls; the fold for a finished run is unchanged.
- The sidebar says "No chats yet" instead of showing an empty section, and the chat's empty state uses the same styling.

### Fixed

- **A line-number gutter no longer needs an opaque fill.** The file preview's numbers now sit in their own column, with only the code scrolling sideways under them — under Glass the old sticky gutter could only be a different colour from the code beside it.
- **The Jev decision-engine key from older builds is migrated once.** A key saved before System One was a provider protocol moves to the official endpoint with its model list fetched from the server, and deleting that provider no longer brings it back on the next launch.
- Floating layers — the selection toolbar, the permission panel, the scroll-to-bottom button and the select menu's scroll arrows — are drawn as glass under Glass instead of staying solid cards.
