### Added

- A conversation resources panel brings together your environment, todo list, subagents, recent output files, and workspace changes. It remembers whether you opened it, appears automatically when there is room, and becomes a compact popover in narrower windows.
- The side browser now includes searchable history, download controls, page capture, PDF printing, and clearer loading and navigation feedback.
- Provider settings can test both a model response and tool-call support. Usage settings now include a conversation-level token and cost breakdown.

### Improved

- The Changes view has a clearer file tree and commit history with branch labels and a graph. Diff selection, staging, commit/amend, pull, and push workflows are easier to follow, including when a commit succeeds but a later network operation fails.
- Conversation search can take you to the matching message, and recent output files can be opened or traced back to the message that produced them.
- Long conversations are read more efficiently, and native context compaction handles oversized history and smaller-context models more reliably.

### Fixed

- Subagents consistently use their configured reasoning level, and scheduled-task results are delivered back to their originating conversation more reliably.
- Computer-control driver update checks run only when requested. Conversation title generation and displayed image/file references are more robust.
