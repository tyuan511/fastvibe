### Added

- **Review mode.** A new dedicated code review built on one built-in reviewer with its own model and thinking level. Start it from the Git pane, from a review dialog, or by typing `/review <focus>` in the composer. Each run reads an immutable snapshot of the selected changes (working tree, staged, branch or a commit), so the report always describes the code it actually read. Results open in their own pane — issues grouped by severity with file position, code excerpt, trigger, impact, evidence and a suggested fix. In the chat you get a compact card: one line per issue with its priority, and a **Fix all** button that sends a normal prompt to the same conversation to work through every finding.
- **Isolated Worktree for new sessions.** A new chat's project row has a 使用独立 Worktree checkbox, off by default and enabled once a Git project is chosen. It creates the checkout on your first send and runs the task there; if that fails the send stops and your draft comes back, and a retry reuses the same Worktree instead of making another one.
- **Refresh the model list.** 设置 → 模型与默认 has a 刷新模型列表 button, for when another program rewrites the provider configuration while FastVibe is running. It re-reads the current mode's configuration and refreshes the provider rows and the model menu. A configuration that fails to load reports an error rather than emptying the list.
- **Mermaid guidance is built in.** A bundled skill covers diagram syntax and layout choices, so diagram requests get a consistent answer without installing anything.
- **Browser: scoped snapshots and native input.** Page snapshots can be limited to one element, with strict references and open shadow DOM support, and typing, clicking and key chords now go through the same native input path in Chrome and embedded webviews.

### Improved

- Markdown images render inline instead of showing a filename chip, keeping their aspect ratio within a size cap. The image viewer zooms with the wheel around the cursor, and clicking a Mermaid diagram opens it full size.

### Fixed

- **Agent Team no longer floods the context.** `list_agents`, `wait_agent` and `spawn_agent` used to return each thread's full system prompt, task and complete last answer, so repeated polling re-sent multi-KB dumps and could exhaust the conversation. They now answer with a compact per-thread digest, repeat calls on an unchanged team return a one-line no-change notice, and the full rows stay in the sidebar only.
- A tool row's label could show a scrollbar even on a single line; its measured height now matches what it draws.
- Vivi re-announced pending questions and failed results on every launch. Announced items are now remembered across restarts, so old ones stay quiet while a new one still announces once.
- Remote clients can now open the image workbench: its methods were reachable by policy but had never been assigned a capability, so they were refused.
