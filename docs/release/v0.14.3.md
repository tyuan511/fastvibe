## Improved

- Added anchored conversation snapshots for remote clients. A client can request only the current conversation tail when its transcript anchor is still valid, with a safe full-snapshot fallback when the branch has changed.
- Improved remote conversation recovery by exposing the snapshot mode and anchor used for merging, reducing unnecessary full-history reloads during reconnects and live-session updates.
