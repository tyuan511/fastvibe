### Improved

- Release notes now open inside the app. The update prompt shows the whole note as formatted text instead of cutting it off, and Settings → About → Release notes opens the note for the version you have installed, with a link to GitHub when it cannot be loaded.
- Long menus scroll. The project filter in the navigation bar and the option sheets stay within the screen and fade out at the edge, so a machine with many projects no longer runs off the bottom.
- Large page titles stay sharp as you scroll. They no longer pass through the blur behind the navigation bar.

This Android APK is signed with FastVibe's release key. Its SHA-256 checksum is included with the download. The iOS build is delivered through TestFlight.
