### 改进

- **更容易找到 Git 变更。** 文件树会标记已修改的文件及其上级文件夹；Git 面板按可折叠的目录树组织变更，也包含已删除的文件。
- **搜索终端输出并打开链接。** 按 Cmd+F 或 Ctrl+F 搜索文本，用 Enter 或 Shift+Enter 切换匹配项，也可以点击终端输出中的 HTTP、HTTPS 链接。
- **从对话中预览文件变更。** 悬停在编辑过的文件上即可查看 diff。每轮先显示三个文件，可以展开其余文件，也可以再次收起。
- **侧栏悬停卡片提供更多信息。** 对话卡片显示完整标题、最近活动时间和工作目录；项目卡片还显示任务总数与运行中的任务数，包含置顶对话。

### 修复

- **Git 文件状态更可靠。** 正确保留 Unicode 文件名、空白字符、重命名后的目标路径，以及未跟踪目录中的文件。以仓库子文件夹打开项目时，状态路径会相对于该文件夹解析。
