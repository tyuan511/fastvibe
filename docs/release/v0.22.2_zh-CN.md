## 不兼容变更

- **决策引擎（Jev）已移除。** 浏览器和桌面的操作改由主模型通过普通的 `browser_*` / `computer_*` 工具一步步完成。设置 → 决策引擎、`browser_task` / `computer_task` / `batch_decide` 三个工具，以及 **System One** 接口格式一并去掉。已保存的、协议是 System One 的供应商在读取时被丢弃，而不是被修复成一个每次请求都会失败的聊天供应商；它的密钥仍留在运行时的环境文件里，不再被引用。已有会话和其他供应商不受影响。

## 改进

- 几百次工具调用的长对话在流式输出时不再越写越慢：已结束的工具摘要被复用而不是每次刷新重建，回合轨只在刻度数量变化时才重新测量。
- 变更视图、分支徽标、文件树和资源面板改为每个工作区共用一个状态轮询，而不是各自一个定时器；diff 只在状态真的变化时重新读取。
- Office 预览在实时服务启动期间先显示静态渲染，打开文档不会再空白一两秒。
- 供应商设置在任何窗口宽度下都是同一个折叠面板，名称可就地编辑，供应商和模型都可拖动排序，每行都有自己的模型检测按钮。
- 转写里的子 Agent 任务图默认收成一行——状态、进度条、`取消全部` 和最大化都留在这一行——点一下才展开。
- 没有内容的思考块结束后不再占一行，回复中间不会再多出一个空的「思考」框。

## 修复

- 历史很大时打开使用统计不再每次启动都重新解析所有转写（294 MB：第二次启动约 1 秒降到几毫秒）。
