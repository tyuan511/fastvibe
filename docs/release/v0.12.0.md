### Added

- Added long-term memory with local full-text memory by default, optional multilingual semantic embeddings, and JEV-enhanced retrieval. Conversations can be captured automatically, recalled during agent turns, searched with `memory_search` / `memory_recent`, and managed from Settings → Long-term memory with a themed interactive relationship graph.
- Added PDF-aware attachments with a dedicated PDF skill, form-filling guidance, text extraction helpers, and automatic agent guidance when a PDF is attached.
- Added macOS Full Disk Access guidance and status handling, including a launch prompt and a Settings → General control for protected folders and files.
- Added selected-text actions to append text to the current conversation or send it to the side chat, plus richer file path previews, reveal, and copy-path actions.
- Added built-in skill discovery and skill-creation workflows, together with architecture-aware Agent runtime manifests and content-hash based runtime release reuse.

### Improved

- Reworked the memory relationship graph as an interactive React Flow canvas with theme-aware cards, directional color-coded edges, dragging, panning, zooming, collision-free layout, filtering, and a detail panel.
- Improved attachment and markdown path handling so pasted text, PDF files, and workspace paths remain useful to the agent while staying clean in the visible transcript.
- Improved decision-engine integration with enhanced-memory configuration, smart approvals, and clearer scenario controls.

### Fixed

- Kept plain HTTP proxy requests on forwarding instead of CONNECT tunneling, avoiding an unnecessary round trip for agent traffic.
- Kept browser engine listing unavailable to remote clients, aligning the server policy with the settings UI.
- Made remote Agent environment loading safer and more deterministic by preserving session identity, mirroring proxy variables correctly, and preventing shell startup values from executing during import.
