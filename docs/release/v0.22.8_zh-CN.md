### 新增

- **给小任务单独配一个轻量模型。** 设置 → 模型与默认 多了一行**轻量模型**：会话标题、AI 提交信息、回复推荐、记忆提取这四类跑在对话之外的请求，现在共用这一个模型。留空就是*跟随会话模型*，也就是以前的行为，所以新装的用户一个额外请求都不会多发，也不会被「必须选一个」卡住。如果选中的模型后来不可用了（供应商被删、被「同步模型」撤下、这台机器没有它的 key），这些小任务会安静地退回对话自己的模型，而不是报错，同时设置里那一行会标成**（已不可用）**，让你看得见、改得掉。压缩摘要、`/handoff`、子 Agent 和 DAG 任务仍然用对话自己的模型——它们要么需要整段上下文，要么是你明确交出去的活。
- **长期记忆也跟着它。** 记忆模型那一行的说明从「跟随默认模型」改成了「跟随轻量模型」；记忆自己那份选择仍然优先于两者。

### 修复

- **没取到标题的会话现在会重试。** 生成标题是 agent 循环之外的一次性请求，引擎的重试设置从来管不到它——于是一次偶发 502 就让这个会话永远没有名字。现在它按引擎自己的重试策略执行，并且遇到「重发多少次都一样」的失败（额度、计费、被拒的 key），或者模型回的不是标题而是一句话时，会提前停下。停止一轮回复也会同时停掉它的标题请求：你已经按停的会话，不会再在后台为标题花钱。

### 改进

- **diff 的行号列对齐了。** 两个序号列算宽度时没把自己那道 1px 分隔线算进去，所以有数字的格子比空格子宽一像素——分隔线恰好在改动行附近一进一出地跳。现在两列都是固定宽度，边框算在内。
- **diff 的每一行不再被包成灰色小块。** Markdown 行内代码的样式原本会作用到 diff 的每一行 `<code>`，于是每行都是「颜色底块里再套一个圆角灰块」，删除行的那层底色只剩下围在灰块外面的一圈。现在一行就是一行，底色通铺整行。
- **「已修改 N 个文件」卡片的滚动条贴到卡片右边缘**，不再从右边往里浮着几个像素；列表里每一行的位置一个像素都没动。
