### Compatibility

- **Mobile compatibility is unchanged from v0.24.0.** Remote access uses the account-authenticated iroh transport. Older mobile builds that use WebRTC or a LAN password cannot connect; a matching iroh mobile build is required. If you depend on an older mobile app, stay on desktop v0.23.0 until you can update both ends.

### Fixed

- **Vivi now shows one notification instead of a duplicated reply and chat panel.** Messages appear only while the FastVibe main window is in the background, hide after five seconds, and remain visible while hovered. Clicking a notification opens its conversation; replying and answering questions happen in the main window.
- **Vivi stays in place when notifications appear or close.** Fixed the position flicker, added support for FastVibe's full-screen Space on macOS, and restored the desktop position when leaving full screen. Settings → Vivi → Behavior → Show messages can turn off notification and interaction bubbles while keeping the companion visible.
- **Stopping a conversation also stops its agents.** Cancellation now reaches delegated work that is still starting, and waiting for agent results can be cancelled. When one selected agent finishes, the parent can collect that result without waiting for every other agent.
- **Agent results and current tasks stay in sync.** Completed and failed results reach the parent agent on its next request, including after a reload or compaction, without starting an idle or stopped conversation. Agent creation entries remain visible outside the process fold; resources avoid duplicate entries, and thread details follow the latest task with its tool calls and thinking intact.
- **Long memory summaries retain retrieval paths across projects.** Oversized summaries preserve section coverage and project lookup entries instead of dropping everything after a prefix. Changes in omitted sections still refresh the memory snapshot, and consolidation retries an oversized summary before accepting it.

### Improved

- **Browser tools work directly in scripts.** Structured results let a script inspect a page, choose elements, fill fields and verify the outcome. The new `browser_wait` waits for a visible element, text or URL condition; failed actions and timeouts stop subsequent steps, and Stop cancels the wait.
- **Running replies show one status below the output**, with elapsed time to a tenth of a second throughout thinking, tools, text and retry waits. The thinking-effort slider has a slimmer track with aligned ticks and effects.
- **Switching the configuration source is clearer.** Settings → About now explains migration, backup and restart in a confirmation dialog, with progress and errors shown in place.
