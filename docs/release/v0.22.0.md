### Improved

- **FastVibe's own records now live in one database** instead of a dozen files that were rewritten whole on every change. What you can feel: a crash or a forced quit no longer costs you the file-rewind safety net — a checkpoint is written the moment it is captured, so **Retry this turn** still offers to put your files back; the merge-on-write protection v0.21.0 gave the conversation list now covers the queued prompts, the task graph, scheduled tasks, reasoning timings and the memory ledger too; and answering a question no longer means scanning everything.
  - The first launch of this version converts the old files and leaves each one beside the database as `.migrated-<timestamp>`. Conversation transcripts stay plain JSONL, and settings, providers and MCP keep their own files — nothing about your configuration moved.
- **Remote (SSH) projects now get what v0.21.0 promised.** This build carries **Agent runtime v15** metadata, so an Office document preview, the file panel's **New file** / **New folder** / **Rename** / **Delete**, and the Git comparison reach the machine that actually holds the files instead of coming back as an unknown method.

### Fixed

- **A reply that used memory no longer ends with an empty code block.** Such a reply carries a citation block for the memory pipeline, and models copy the protocol's example — which is drawn inside a code fence. Only the tags were hidden, so the fence stayed behind and drew a stray box on every one of those replies; the wrapper now goes with it, including a fence whose block is still being written.
- The sidebar's search no longer matches that block. Looking up a conversation id used to return a hit from text the reader was never shown.
