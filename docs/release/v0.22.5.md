### Fixed

- **The copy button on a failed tool call's message stays in its corner.** A long error — an edit's `Could not find edits[0] in /Users/…/thinking-off.ts` — wrapped over several lines and the icon drifted down to the middle of the block; it now sits at the top-right whatever the message wraps to, and a long path can no longer run underneath it.
- **AI-generated commit messages, chat titles, `/handoff` summaries and memory extraction no longer come back empty.** A model that thinks by default was spending the whole reply budget on its reasoning and returning nothing, which surfaced as 「生成提交信息未完成」 with no further explanation. Those requests now ask the endpoint to skip thinking, and a model that refuses that form is re-asked without it. When a generation still fails, the error now says how it ended instead of one unexplained line.
- **A chat title that was cut short now looks cut.** When the first title never got generated, the row showed the head of your prompt with no indication that it stopped at 24 characters; it ends with an ellipsis now.
- **A thought folded into a tool line reads like any other thought** — it opens to its reasoning, shows how long it took, and no longer appears as a plain paragraph with no way in.
