### Added

- **Dynamic subagent orchestration.** The main agent can create a task graph and run up to five independent tasks at once, starting dependent tasks only after their inputs are ready. Tasks can reuse your configured subagents or use a role written for the task, and work across local and SSH conversations.
- **Live task graphs and execution history.** Follow progress inline in the chat, expand the full graph, or open individual tasks from the sidebar to inspect their instructions, results, and execution transcript. Cancel, retry, or resume work while keeping completed results; graphs and transcripts survive an app restart, with interrupted work waiting for you to resume it.
- **Hand off a conversation with `/handoff`.** Give the next goal and the current model writes a self-contained prompt from the conversation's active context. Review or edit it, then submit to start a new chat with the same model. The original chat stays available, and a handoff started on a phone opens its new chat there too.

### Improved

- Selected text in chats and file previews now has a shared action bar for copying, adding it to a conversation, or asking in a side chat. Code and diff previews can quote the selection into the composer.
- Subagent progress, transcripts, and execution tabs are kept separate by conversation and SSH host, even when different hosts use the same task identifier.
- Opening prompts sent by the agent appear immediately while the new chat prepares its first turn, remain available after switching chats or reconnecting, and populate the sidebar's title and preview.

### Fixed

- Editor dialogs preserve the initial text supplied by extensions. Clicking outside an editor or text-input dialog no longer discards what you have typed; Cancel, the close button, and Escape still dismiss it.
