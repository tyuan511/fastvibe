### Improved

- Long conversations open with recent messages first and load older or larger content when needed. A local preview helps while reconnecting, then gives way to the host's current conversation state; Copy All still retrieves the complete conversation.
- Interrupted file downloads retain their progress and can resume after reconnecting. You can also cancel a download and clear its partial data.
- Connection diagnostics now show the stage that needs attention, recent connection timings, and a report you can copy for troubleshooting.
- Clearer loading and synchronization states prevent actions from using incomplete or stale content. Compaction and model changes are easier to follow in the transcript.

For the latest on-demand conversation loading, update your FastVibe desktop host to **v0.20.4 or newer**. SSH hosts use the corresponding **Agent runtime v14 or newer**.
