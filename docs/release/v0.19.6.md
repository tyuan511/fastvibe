### Added

- **Scheduled tasks.** A new page lists instructions that run on their own — once, every day, or on chosen weekdays — each in a fresh chat, in a project or a scratch workspace. You can also ask the agent to set one up. Closing the window leaves them running (a tray icon keeps a way back on Windows and Linux); quitting the app stops them, and runs missed meanwhile are picked up the next time FastVibe starts.
- **The file pane can edit.** Code, Markdown, HTML and diffs open with syntax-highlighted editing and a Save button; rendered documents and images stay view-only so the original is never overwritten. CSV and spreadsheet sheets open as a table you can filter and sort, Markdown reads as a document with an outline and its front matter, and a path breadcrumb lets you jump to any folder above the file. The file list is resizable.
- **A phone can open and download the files a reply produced** (needs the matching update of the FastVibe app).

### Improved

- **Plugins has its own page** in the sidebar instead of living inside Settings, so chats keep running while you browse and install.
- **Computer control is no longer part of the installer.** The component (about 80 MB) is downloaded the first time you turn on Settings → Computer control, with progress and a retry button, which makes the download for everyone else much smaller.
- **Long runs read shorter.** Consecutive quiet tool calls collapse into one line such as "Ran 2 commands, Read 3 files", and once a run finishes, everything but the final answer folds behind its "took …" row.
- **Menus and dialogs are easier to read** over the glass effect: floating layers are more opaque, so the text behind them no longer shows through. The interface font is now Instrument Sans.

### Fixed

- **A chat that generated many images could stop answering.** Every earlier picture was sent back to the model with each request — one chat reached 58 MB across 26 images — and gateways refused it (413, 502 or a timeout) whichever model was behind them. Pictures are now shrunk when they arrive, the full-size copy is kept on disk for the chat to show, and anything still too large is left out of the request with a note naming its file, so the agent can read it again if it needs it. Chats that already grew large recover on their next message.
- **An HTML page now runs in the side pane.** Scripts the page wrote inline were blocked, so a page that animates in a browser sat still. It is served as a document of its own: inline code and https libraries run, while the page still cannot read your files or reach FastVibe.
