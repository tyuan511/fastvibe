### Improved

- **More capable subagent orchestration.** Complex work can use up to three levels of scoped coordinators. Coordinators release their execution slot while waiting for children, and can revise queued tasks or send new guidance to running tasks.
- **Better control of task context and results.** Tasks can choose which prerequisite results enter their context, with a combined input budget checked against the model's window. Complete results and evidence are saved per attempt and can be read in pages or searched without filling the main conversation.
- **Shared execution limits and safer parallel work.** Turn and token budgets include child tasks and survive retries; each task also has an execution deadline and retry limit. Overlapping declared write paths are scheduled in sequence, and tasks retain their parent model choice after a restart.
- **Task views for phone browsers.** A compact progress row opens a task list with coordinator and child relationships. Details, evidence, results and execution history remain readable on narrow screens, with stop, retry and resume controls.
- **Memory preparation no longer holds up a message indefinitely.** Automatic recall uses a short deadline and already downloaded embedding models, and stopping a conversation cancels its pending preparation.

### Fixed

- Task completion notices are retained until delivered. A previously cancelled task no longer suppresses later results, and waiting for one task does not consume another task's outcome. Blocked work is reported explicitly instead of being treated as successful completion.
- Remote connections tolerate large histories and continuous output on slower links while still closing genuinely stalled connections.
- Unanswered clarification questions stop waiting after five minutes, allowing work that does not depend on the missing answers to continue.
- The sidebar update control remains visible while an available update is being checked again.
