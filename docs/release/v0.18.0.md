### Added

- **Official remote connection.** A phone signed in to the same FastVibe account finds this computer by itself and connects directly, with no password and no address to type. When a direct path is not available the connection goes through FastVibe's relay. Settings → Remote access shows each connected device and whether it is connected directly or relayed.
- **One computer name.** Settings → Remote access → Computer name is the name your phone, the device list and the console all show. It starts as this computer's own name, and changing it takes effect without dropping a phone that is already connected.
- **LAN access stays, as its own password.** With a LAN password set, a phone on the same network can still scan the QR code or find the computer nearby and connect. Account discovery works without that password.

### Improved

- Opening a chat from the phone is much faster over a relayed connection. The phone only draws a one-line summary of each tool call, so the transcript it downloads no longer carries the full arguments and output of every call.

### Fixed

- Signing in completes when the browser comes back to `localhost` as well as `127.0.0.1`.
- A phone on another network can connect even when this computer's traffic goes through a proxy. The connection now waits until this computer has found its own public address before it starts pairing with the phone.
