### Fixed

- **The remote connection no longer drops on its own while you are using it.** A large reply was enough to make the server close a healthy client: the write buffer counts bytes still being compressed, not only bytes the network has not accepted yet, so a long transcript crossing the 2 MB mark was read as a client that had stopped reading. FastVibe now allows that burst and only ends a connection that stays congested, which keeps the memory bound without dropping a phone in the middle of a conversation.
- **The phone page works from the remote client again.** The desktop pages served at a LAN or tunnel address are back to a buildable state after the phone-page split, and the attach button no longer throws when it opens the file picker.
