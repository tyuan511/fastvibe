## 新增

- **macOS Dock 角标显示你不在这段时间里跑完的会话数。** 打开其中一个、删掉它或解绑它的远程项目，数字都会减少；重启后仍然准确。它和系统通知各自独立，点回应用也不会把数字清空。

## 修复

- **模型管理恢复成单列供应商列表**，每个供应商的配置和模型列表在原地展开，而不是左列表右详情。供应商和它的模型都能拖动排序（按 id 保存），名称就在那一行里改。
- **输出速度现在描述的是一次请求。** 它以前是本轮剩余输出除以本轮所有来回，所以一轮问了四次就报成四次的平均值，中间一段长工具调用看起来像模型变慢了。现在是最近一次已完成请求自己的输出除以它自己的耗时——含首 token 等待、不含工具等待——没有计时的请求显示 `—`，不会借用上一次请求的数字。这一行的说明也照实写了。
