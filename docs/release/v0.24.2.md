### Improved

- Agent tool calls now show readable actions with clickable avatars and names. Open the corresponding thread directly from creation, waiting, messaging, follow-up, interruption, and list actions; multiple targets have separate links.
- Active tasks now share a compact nine-dot running indicator across conversations, tools, task lists, and agent resources. Page and button loading indicators keep their existing appearance, and the new animation respects reduced-motion preferences.
- The working timer now displays whole seconds instead of tenths of a second.
