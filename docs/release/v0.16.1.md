### Added

- **Sync configuration to the global pi install.** **Settings → About** shows the embedded pi version and can write the connected providers, default model, thinking level, and MCP servers into the pi install on this machine. The confirmation offers **Merge** (matching entries are replaced, entries that exist only in pi are kept) or **Replace** (providers, credentials, and MCP servers are swapped for this configuration). Sessions, themes, and installed packages stay put. API keys are written into `~/.pi/agent`, and the previous files are copied aside first.
- **System One as an API format.** In model management, a provider or model can use **System One**. Those models are for the decision engine only — they do not appear in the chat model list. **Settings → Decision engine** lists only System One providers and models. An existing Jev API key is turned into the official Jev provider (`https://api.typesafe.ai/v1`) on launch, and a decision engine that was already on is pointed at it.
- **Copy a message, and quote code from a preview.** Right-click a transcript row to copy it (or the text you have selected). A file preview can copy its contents, and code or diff previews can drop the selection into the composer as an attachment.

### Fixed

- Stopping a run now ends a browser tool call that is still waiting, instead of leaving it until its own timeout.
- A completion or failure notice is delivered to a phone even when the desktop is already showing that chat.
