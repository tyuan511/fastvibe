## Added

- **Reply suggestions:** after an assistant reply finishes, FastVibe can suggest your next message in the empty composer. Press Tab to fill it in, then edit or send it yourself. You can turn this off in Settings → General.
- Chats that finish in the background, and their project folders, now show an unread indicator so completed work is easier to find.

## Improved

- Refreshed provider settings with clearer connection status, a more spacious model list, and consistent controls for conversation and project defaults. Model checks report response and tool-call results in a toast, with an action to edit a model when needed.
- Browser and computer tasks now check whether the state relevant to a decision has changed, reducing unnecessary retries caused by unrelated changes.
- Updated the embedded Pi runtime to 1.3.0 and removed unused interface and helper code.

## Fixed

- Answering a background chat's question now clears its waiting indicator even when another chat is open.
- Corrected file-tree indentation beneath project folder cards.
- Fixed notification positioning in the glass theme.
- Kept databases created by a recent development build compatible when opening this release.
