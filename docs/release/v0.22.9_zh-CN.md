### 新增

- **设置 → 技能 有了 Skill 市场。** 这一页现在自己会搜 [skills.sh](https://skills.sh)，看中哪一行点一下就装到 FastVibe 自己管理的那个目录——同一个列表、同一个删除按钮，而且不用重启：装完当场就能在装它的那个对话里调用。搜索结果按关键词缓存，点「重新搜索」可以绕过缓存。整条路上没有一个只属于桌面端的对话框，所以手机通过远程访问也能装技能（在这件事上手机反而比「导入」更管用，因为导入要开一个本地文件夹选择器）；智能体也能用自己的配置工具一句话搜、一句话装。安装绝不会悄悄顶掉你已经有的技能：只有 FastVibe 自己装过的那一份允许覆盖，你手写的技能——`~/.agents/skills` 里的、项目里的、随应用内置的——一律拒绝并说明原因，因为写第二份进去只会加载不上却告诉你装成功了。（它取代的是以前让 `find-skills` 去 shell 一句 `npx skills add` 的做法：那句话要求 Node 工具链在 PATH 上（安装版里不成立），而且会装到它的 `--agent` 参数恰好映射到的那个目录，FastVibe 常常读不到。现在这条技能直接指到这个面板。）工具栏变成**搜索 / 刷新 / Skill 市场 / 导入**：「导入」从 ⋯ 菜单提到了一级按钮，手写技能的「新建」入口去掉了。
- **回复里的代码块现在长得像它引用的那个文件。** 围栏代码块加了行号列，以及该语言的文件图标——用的是文件预览和左侧文件树同一套图标。只有一行的代码块不画行号列；`diff` 代码块保留 diff 视图自己的行号（从 hunk 头读，不是数行数）；没有对应图标的语言干脆不画图标，而不是画一张空白页。顺带修掉一个藏着的排版问题：高亮之后的每一行比没高亮时高一个像素，语法一加载行号就从代码上滑偏了。

### 改进

- **网络代理的设置改完即生效。** 这一页以前把改动攒成一个草稿，要按「应用」才算数——也就是说没人按那个按钮时，屏幕上画的从来不是网络实际的状态。现在每一行一改就写：开关和下拉立刻生效，地址在失焦或回车时写入，所以正在输入的半个 `http://1` 不会顺手成为当前走的路线。写入失败时控件退回真正生效的那份设置，并用一条轻提示说明原因。协议、地址、端口也合并成了一个地址（`http://host:port`、`socks5://[::1]:1080`，端口可省），旧版本写的设置文件在读取时会自动折成这一个地址——已经在走代理的安装，升级之后照旧走，什么都不用重填。
- **更新检查没那么频繁了。** 后台检查从每十分钟一次改成每小时一次，最多只是那个角标可能说的是一小时前的版本，其余没变：**立即更新**本来就会在屏幕上的提示过期时重新读一次发布列表，真正拦住「装到一个被取代的版本」的一直是它，不是这个间隔。

### 修复

- **打开或切换会话时不再闪出互相重叠的对话轮次。** 现在会等列表量完每一行的真实高度再画：头几帧是按估计值排版的，一轮比估计值高时就会压住下面那一轮。
- **最大化窗口不再以错误的尺寸显示出来。** 启动时恢复成最大化，以前会先把小窗口的排版拉伸铺满大窗口、随后再重新排一次；现在它先按全尺寸画完，再让自己可见。
