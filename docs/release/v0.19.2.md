### Changed

- **Long-term memory now works the way Codex's memory does.** Settings → Long-term memory is a single switch (off by default) and a choice of which model does the work. When it is on, a conversation that has been quiet for six hours is read once and distilled into a note and a recap; a background agent then consolidates them into a handbook (`MEMORY.md`) and a one-page summary. Each turn, the agent is shown that summary and looks things up in the files only when the request could depend on earlier context. Everything is Markdown on your computer: open the folder from the settings page, or clear it with one button. Turning memory off stops reading, writing and injecting but keeps the files. Secrets are redacted before anything is stored, and the prompts are Codex's own.
- **Heads up: the previous memory is gone.** The default / semantic / JEV-enhanced modes, the relation graph and the 118 MB embedding model have been removed, along with the "Enhanced memory" scenario in the decision engine. The old index is deleted on first launch and is not carried over; memory starts empty and off. While it is on, finished conversations are sent to the model you choose to be summarised.

### Improved

- The installer no longer bundles the local embedding runtime that the old memory used, and ships one copy of a shared library instead of several.
- The build now fails if the packaged app is missing a dependency, so a release like v0.19.0 cannot ship without one again.
