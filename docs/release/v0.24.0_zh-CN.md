### 不兼容变更

- **现有手机客户端连不上这个版本。** 远程访问改成了账号认证的 iroh 通路，而目前放出去的手机客户端只会旧的 WebRTC 连接和局域网密码。所以桌面端升到 v0.24.0 之后，手机就连不上这台电脑，要等对应的手机版本发布。没有切回旧通路的开关——如果你现在依赖手机访问这台电脑，先留在 v0.23.0，等手机版本出来再升。

### 新增

- **手机改用 iroh 连接。** 设置 → 远程访问 现在只有一个开关、一条通路：这台电脑把 iroh 端点注册到你的账号，同一账号登录的手机直接连上——不用地址、不用局域网密码、不用扫码。面板会显示端点身份、当前连着的每台设备，以及每一台走的是直连还是中转，还有账号剩下的中转额度。这需要新版 FastVibe 手机客户端；原来的 WebRTC 账号连接和局域网监听不再是产品通路。
- **Vivi 桌面伴侣。** 设置 → 通用 → Vivi 桌面伴侣 会在桌面上放一个小 3D 角色。她会跟着智能体的状态动——思考、跑工具、完成、失败——你拖她、扔她、接住她时也会有反应，带一个说短句的气泡，以及一个能往当前会话发提示词的对话面板。大小、透明度和配色（天空、葡萄、薄荷、蜜桃、云）都可调；默认关闭。
- **设置 → 关于 → 引擎** 可以选择内嵌引擎把配置存在哪：FastVibe 自己的运行时（默认），或者你的全局 pi 目录。切换会先备份目标、迁移供应商、凭据、默认模型、MCP 服务和资源目录，然后重启。正在运行、有提问挂着或有子 Agent 在跑时不允许切换；源目录会保留，切回去不用重建。会话、队列、检查点和定时任务都不会移动。它取代了原来单向的「同步配置到全局 pi」按钮。

### 改进

- **委派变成了团队，而不是一次并发。** `subagent` 工具没有了；智能体改用 `spawn_agent` 建立常驻线程，用 `send_message` / `followup_task` 给它发消息，用 `wait_agent` 收结果，用 `interrupt_agent` 停掉某一个。线程存在数据库里、由 Main 驱动，所以委派出去的任务能活过界面重载，也能从任何客户端介入；侧栏给每个线程一个名字和头像。线程被中断后历史还在，后续消息接着同一件事做。
- **思考强度改成滑杆。** 选推理强度现在是沿模型自己的档位拖一下，而不是点进子菜单挑一档；拖动时会预览当前档位。
- **电脑操控能力大幅增强。** 智能体可以拖动、移动光标、读取光标位置和状态、改窗口大小、截取某个区域，还能用 `computer_verify_state` 自查——在报告成功之前断言窗口的位置尺寸或某个元素的值。`computer_batch` 会返回每一步的结构化结果，一串操作因此能说清每一步到底发生了什么。
- **上下文可以在后台自己整理。** 设置 → 偏好设置 → 对话 → 后台压缩上下文（默认关闭）会在这一轮结束后、上下文超过 75% 时提前开始整理，下一轮直接用整理好的内容，而不用等摘要。90% 的兜底会等这个任务、并重新核对后再决定是否强制再压一次；后台任务失败绝不会挡住发送，进度、成功和失败都会发通知。
- 自动归档最短可选 **3 天**，适合希望做完的事尽快离开侧栏的人。

### 移除

- **DAG 任务编排已移除。** `dag_*` 工具、任务图、调度器和「动态任务编排」设置都删掉了，委派统一走 Agent 线程。其余行为不变——独立任务本来走的就是普通委派。
