### Improved

- **The embedded pi SDK is now 1.2.0.** Settings → About shows the new kernel version. Stopping a reply while it is still preparing no longer leaves the chat marked as running, and Continue still finishes the run.
- **Independent sub-agents are not a task graph.** Several tasks that do not need each other's results run through the subagent tool. A task graph is created only when later work depends on an earlier result.
- **Rename a project from its folder dialog.** The sidebar no longer has a separate rename action. Edit the name in the project's folder dialog. A remote project can be renamed the same way, without a folder list. Actions on an extra folder stay hidden until you hover that row.
- **A folded tool summary stays one line.** A batch of tool calls uses the same weight as a single call, shows an icon, and cuts a long query with an ellipsis instead of drawing it over the next clause. Thinking and working labels use that same regular weight.
