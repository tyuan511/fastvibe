### Fixed

- **Remote access no longer drops when the Mac goes idle.** "Keep awake while running" used to hold the machine awake only while an agent was working, so a Mac left idle between prompts fell asleep under a connected phone and took the connection and the tunnel down with it. It now also keeps the Mac awake for as long as remote access is on. Closing a MacBook's lid still puts it to sleep — macOS does not let an app prevent that — and the setting now says so.
