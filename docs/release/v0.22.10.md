### Added

- **A menu bar on macOS.** FastVibe now installs its own application menu, which mainly means one thing: **Settings is reachable from the menu bar** — it used to be nowhere in it, because the app menu only held About / Services / Hide / Quit. ⌘, opens it, and File / View / Window / Help carry the app's own commands (new chat, search, the side panes, the website) instead of Electron's generic ones. Shortcuts you record in Settings → Shortcuts are taken over by the menu, so one press does one thing rather than firing twice, and while you are recording a new shortcut the menu lets go of that key. Reload, Force Reload and Developer Tools appear only in a development build. Windows and Linux are unchanged — they draw their own title bar, and a native menu would sit on top of it.

### Fixed

- **Your own messages are no longer formatted as Markdown.** A pasted URL followed by Chinese used to turn the rest of the sentence into one link — a bare URL runs until the next space, and a Chinese sentence has none — and clicking it opened an address that does not exist. Prompts now show exactly what you typed: line breaks kept, a long URL or path still wrapping inside the bubble. Replies are unaffected, and the phone renders your messages the same way now.
- **A short prompt is shown in full.** Only a prompt over 500 characters collapses behind an Expand row; before, the fold was decided by rendered lines, so a sentence that happened to wrap onto a third line needed a click to finish reading. The threshold is the same 500-character line the composer already folds a paste at.
- **A project folder only repeats itself when it is collapsed.** Its running and unread marks used to sit on the folder row even while every chat inside was listed right below with its own mark in the same column. Expanded, the chats say it; collapsed, the folder does.
