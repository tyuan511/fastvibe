### 新增

- **macOS 有了自己的菜单栏。** 这条改动的实际意义主要是一个：**设置终于能从菜单栏进去了**——以前它在菜单栏里根本没有入口，应用菜单只有「关于 FastVibe / Services / 隐藏 / 退出」。现在 ⌘, 就能打开，文件 / 编辑 / 视图 / 窗口 / 帮助 装的也是产品自己的命令（新对话、搜索、侧边面板、官网），不再是 Electron 那套通用项。你在 设置 → 快捷键 里录下的快捷键会交给菜单接管，所以按一次只做一件事、不会被页面再执行一遍；正在录制新快捷键的那几秒里菜单会先松手，让录制框看得见那个键。重新加载 / 强制重新加载 / 开发者工具只在开发版里出现。Windows 和 Linux 不变——那两个平台的标题栏是应用自己画的，再加一条原生菜单只会压在它上面。

### 修复

- **你自己发的消息不再按 markdown 渲染了。** 以前粘一个网址再加一句中文，整句话的后半段会变成一个链接——裸网址的自动链接一直到下一个空白才结束，而中文句子里没有空白——点下去是一个根本不存在的地址。现在提示词显示的就是你打下的字：换行照原样保留，很长的网址或路径仍然会在气泡里折行。回复不受影响；手机端也改成同样的画法。
- **短的提示词整段显示。** 只有超过 500 字的提示词才会收成一行「展开」；以前的判断标准是渲染出来的行数，于是一句话只要碰到第三行也得点一下才读得完。这条 500 字的线用的是输入框折叠粘贴内容时同一条规则。
- **项目文件夹不再在自己展开时重复说话。** 它的「运行中」和「未读」标记以前一直画在文件夹行上，哪怕文件夹里那些会话就列在它下面、各自在同一列带着自己的标记。展开时由那些会话说，收起时才轮到文件夹说。
