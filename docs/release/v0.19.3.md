### Improved

- **Remote access connects more reliably from other networks.** Before an official-connection call, FastVibe now checks how this computer reaches the internet and sets the call up to match. If a proxy or VPN owns the default route, the call no longer advertises the tunnel's far end as your address, so the phone connects through your real network instead of through the proxy or not at all. It also picks the STUN server that actually answers, handles routers that hand out ports in order, and asks a router that supports NAT-PMP or UPnP to forward a port for the length of the call. The path shown in Settings → Remote access is now the one the connection really uses. The router port-forwarding is new and has been tested against simulated routers only; if remote access misbehaves behind a particular router, please report it.
- **The browser pane no longer flashes off-screen while it opens.** The page used to sit off the right edge of the window until the opening animation ended, and a page opened by a tool on an empty pane popped the pane open. The page now follows the pane as it slides in, and a tool-opened tab stays quiet until you open the pane.
- **Larger file previews.** Images and PDFs up to 16 MB (was 1 MB) and text files up to 4 MB now open in the side pane, so ordinary phone photos are no longer refused.

### Fixed

- **"Send now" on a queued message is reliable.** Stopping the reply in flight to send a queued message used to be read as a failure: the queue paused with "the response failed" and you got a task-failed notification for the very message you had just sent, and the chat could look idle for a moment between the two replies. The clicked message is now sent next, the chat stays working across the gap, whatever the stopped reply still said stays above the new turn, and the turn is taken back cleanly if it cannot be sent.
- **The "processing" clock no longer counts a failed attempt.** After a reply failed or was stopped and you continued it or retried it, the clock included the failed attempt and the wait before you came back. It now starts from the attempt that is running, and opens at 1 second rather than 0.
