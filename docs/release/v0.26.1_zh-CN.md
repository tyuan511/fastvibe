### 新增

- 图片工作台：输入区新增参数选择器，可为每次生成单独选择模型、尺寸与质量；生成结果按会话归档为图库，每张结果图上提供引用按钮，选中即可直接作为下一次生成的参考。

### 改进

- 转写中的 Agent 工具行：`list_agents` 现在会并入批量工具运行折叠展示，运行中的等待与团队变更仍保留独立行。

### 修复

- Agent Team 追加任务：followup 消息现在是新一轮任务的唯一来源；移除了 `task` 参数，不再出现任务简介与实际发送内容不一致的轮次。
- 局域网发现：当 VPN/隧道接管默认路由时，一次组播发送失败曾导致局域网广播停止直到重启应用。发现广播现在会按退避自动重试，手机端的局域网线索可以自行恢复。
