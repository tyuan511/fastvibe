### Added

- **A lightweight model for the small jobs.** Settings → Models & defaults now has a **Lightweight model** row: one model for the four requests that run beside your conversation — chat titles, AI commit subjects, reply suggestions and memory extraction. Leaving it empty means *follow the chat's own model*, which is exactly what earlier versions did, so a fresh install sends no extra request and nothing is forced to change. If the pinned model ever becomes unavailable (its provider deleted, dropped by **Sync models**, no key for it), those jobs quietly fall back to the chat's model instead of failing, and the settings row marks the pin **(unavailable)** so you can see it and pick another. Compaction summaries, `/handoff`, subagent runs and DAG tasks deliberately keep the conversation's own model — they need the full context or are work you explicitly handed over.
- **Long-term memory follows it too.** The memory model row now reads *Follow the lightweight model* rather than *Follow the default model*. Its own pin still wins over both.

### Fixed

- **A chat that failed to get a title now retries.** Title generation is a one-off request outside the agent loop, which the engine's retry setting never reached — so a single transient 502 cost a conversation its title for good. It now runs under the same retry policy as the rest of the engine, and stops early on a failure that would fail the same way every time (quota, billing, a rejected key) or on a reply that isn't a title at all. Stopping a run also stops its title request, so a chat you stopped doesn't keep spending on a title behind it.

### Improved

- **Diff line numbers line up.** The two gutter columns measured their width without the 1px separator between them, so a numbered cell and a blank cell were a pixel apart — the rule between the gutter and the code stepped in and out on exactly the rows next to a change. Both columns are now fixed width, border included.
- **A diff row is no longer drawn inside a grey chip.** The inline-code style used by markdown reached every line of a diff, so each row was a rounded box sitting inside its own colour, and a removed line's tint survived only as a rim around it. A row is a row now: the colour runs the full width.
- **The changed-files card's scrollbar sits on its right edge** instead of floating a few pixels in from it. Nothing else about the list moved.
