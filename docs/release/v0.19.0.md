### Added

- **A phone on the relay keeps its session when the relay's credential runs out.** The relay now issues short-lived credentials, and a relayed connection ends with the one it was made with. Shortly before that, the phone opens a second connection and moves over; this computer keeps the phone's earlier connection open until the phone lets go of it, so nothing is dropped and no "reconnecting" banner shows. Direct connections never depended on the credential. Needs **FastVibe Mobile 0.5.2 or newer**.

### Improved

- **The official connection recovers sooner.** The list of STUN servers is used as soon as there is one and refreshed behind the call, so a call with nothing to gather with waits 3 seconds instead of 15. Signaling is checked every 15 seconds and at once when a call ends, so a network change no longer leaves this computer unreachable for up to 70 seconds.
- **Large frames on the relay are compressed off the main thread**, in order.
- **Updated dependencies**, including cua-driver 0.34.0 for computer control.

### Fixed

- **Settings → Providers no longer re-renders endlessly** on an install that never pinned a project default.
- **Remote access stays on across launches.** Saving an unrelated setting, such as dragging the sidebar, could write an old remote-access value back and turn it off at the next start.
- **Signing in no longer fails the first time.** The sign-in code is now exchanged under the same address the browser was sent to.
- **A browser or run opened by a tool no longer pops the side pane open.** It waits in the tab bar until you pick it.

### Performance

- **The branch chip no longer interferes with git.** Status polling stopped taking `index.lock`, so the agent's own `git add` and `git commit` no longer fail while a poll is in flight, and the polls run in parallel.
