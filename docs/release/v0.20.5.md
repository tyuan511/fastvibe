### Improved

- Simplified the conversation resource panel: todo lists now show completion progress without the previous-plan label or the extra message shortcut.
- Expanded resource lists now offer a **Show less** button. Active subagents, finished subagents, and recent outputs can be expanded and collapsed independently.
- Recent output files now highlight the full row, including the message shortcut on the right.
- The changes file tree stays beside the diff at every panel width. It uses the same default width and resizing behavior as the file panel, stops at a minimum width instead of collapsing while dragging, and can still be hidden with its toggle.
