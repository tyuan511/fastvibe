### Added

- **A project can include several folders.** Create a project from more than one local folder, or edit one later to add a folder, remove one, or choose which is primary. The agent is told about every folder. The file tree groups them by root, and the Git pane switches between repositories when there is more than one. Changing the primary folder applies to new chats; chats you already have keep the folder they were using. Retry still restores files, with a separate baseline for each repository.
- **Type @ to attach a project file.** In a project chat, `@` opens a list of matching files. Picking one adds it as an attachment and takes the `@query` out of the draft, so it is not sent twice. An address such as `user@host` stays ordinary text.
- **The file editor shows line numbers.** The numbers stay put when a long line scrolls sideways.
- **A scheduled task can report back.** A task the agent creates from a chat posts its outcome into that chat when the run finishes on its own. The task page names that chat and can open it. A task you create on the page itself does not report anywhere.

### Improved

- **Compaction sits between turns.** "Compacting context" and "Compacted context" are their own divider, the same way a model switch is, instead of appearing inside the reply they followed. Stopping a compaction is shown as cancelled, not as a failure.
- **A live thought stays readable.** While the model is thinking, the collapsed row follows the latest text as one line, instead of restarting on every linebreak. A thought between tool calls stays visible and is not folded into the summary of those calls. The files a reply changed are listed once the run has finished.
- **Hide the file tree.** On a wide file pane, with a file open, the tree can be collapsed so the file uses the pane. A narrow pane still swaps between the tree and the file.

### Fixed

- **A repetition loop is not the same as pressing Stop.** When a reply is stopped because the model repeated itself, the transcript says so and still offers Continue. Your own Stop still reads as Interrupted.
