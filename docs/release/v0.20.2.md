### Improved

- **The model divider appears when the request is sent.** Switching models no longer waits for the reply to start. A reasoning model that stays quiet still shows which model is working. Changing the pick again before sending still draws nothing.
- **Hovering a project shows its folders.** The card shows the project name, whether it is local or remote, the primary folder, and any other folders.
- **SSH agents upgrade to the runtime that sends Claude adaptive thinking.** This build carries agent runtime v13. The next connection updates an older agent on the host, so a Claude model that rejects budgeted thinking no longer fails with a 400.
