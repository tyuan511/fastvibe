### Fixed

- **Fixed FastVibe failing to start after updating to v0.14.5** with `Cannot find package 'cross-spawn'`. The packaged app was missing several runtime dependencies of the upgraded agent engine (including `cross-spawn`, the MCP SDK and the Anthropic SDK); they are bundled again. If you are on v0.14.5, please update to this version.

**Full Changelog**: https://github.com/tyuan511/fastvibe/compare/v0.14.5...v0.14.6
