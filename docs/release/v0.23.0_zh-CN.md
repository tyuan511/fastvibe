### 改进

- 编辑或重试提示词时，现在会保留粘贴文本、技能指令、文件附件和图片元数据。附件卡片仍可单独编辑；只有图片、没有文字说明的提示词也可以直接发送。
- 大型和长时间运行的会话现在会减少重复的聊天视图计算。已经完成的消息行会复用原有对象，只重建正在输出的尾部，从而降低流式回复期间的 renderer CPU 和垃圾回收压力。

### 性能

- 同一轮中，checkpoint 只写入新发现的文件，不再随着文件列表增长反复重写完整文件集合。
- 事件分发减少重复 payload clone 和重复 scope 扫描，客户端 batch 大小计算也会缓存。
- 大型 JSONL 转写使用流式读取；只追加内容时只解析新增的 byte range。
- 流式 Markdown 对较大的正在生成内容降低重复解析频率。代码高亮和工具参数更新会丢弃过期的中间 snapshot，同时保留最终结果。
- 版本中加入可重复的 wall time、CPU、内存、RSS、event-loop 和长尾延迟基准，后续性能改动可以持续与本版本对比。

### 修复

- 提示词重建现在在桌面端、转写重载和远程客户端之间使用相同的元数据与附件顺序，避免编辑后的 turn 静默丢失粘贴内容或附件。
