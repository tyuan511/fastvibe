### Added

- **Open and download the files a reply produced.** Under a finished reply, the files it wrote or edited, and anything the agent presented, are listed as rows (four at a time, the rest behind "More"). Tap one to preview an image, a Markdown file or a text file right in the app, or to download it. Anything else — a PDF, a spreadsheet, a video — is downloaded and handed to the system to open. On iPhone the downloads are saved in the Files app, under FastVibe; a file that changes while it is being read, or a download you leave, never leaves a half-written copy behind.

  Update your FastVibe host to **v0.19.6 or newer** to use it.
