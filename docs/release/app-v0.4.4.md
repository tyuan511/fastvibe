### Fixed

- Switching the app language now updates screens that are already open. Device lists, chats and settings change immediately, including a screen you return to after changing the language, so the app no longer needs to be restarted.

### Improved

- Prompts no longer show the image-resize note the host appends after a photo, and the photo itself is unchanged.
- Photos in the composer no longer flicker while you type.

Update your FastVibe host to **v0.17.4 or newer** so a language change reaches the phone and the desktop together.

This Android APK is signed with FastVibe's release key. Its SHA-256 checksum is included with the download. The iOS build is delivered through TestFlight.
