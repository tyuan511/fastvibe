### 改进

- Agent 工具调用改为可读的动作描述，并展示可点击的头像和名字。创建、等待、发送消息、继续任务、中断和查看列表时，都可直接打开对应线程；多个目标分别提供入口。
- 会话、工具、任务清单与 Agent 资源中的运行状态统一使用紧凑的九点网格。页面和按钮的普通加载动画保持原样，新动画遵循系统的减少动态效果偏好。
- “工作中”的耗时改为整秒显示，不再显示小数。
