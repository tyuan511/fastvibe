### Added

- **A skill marketplace in Settings → Skills.** The pane searches [skills.sh](https://skills.sh) itself now and installs what you pick with one click, into the folder FastVibe already manages — the same list, the same delete button, and no restart: a skill you just installed is callable in the conversation that installed it. Results are cached per search and **Search again** goes around that cache. Nothing in the path is a desktop-only dialog, so a phone connected over remote access can install skills too (it can do more here than the **Import** button, which needs a folder picker), and the agent can search and install in one sentence through its own config tools. An install never quietly replaces a skill you already have: only a copy FastVibe installed itself may be overwritten, and a same-named skill of yours — from `~/.agents/skills`, a project, or the built-ins — is refused with the reason, because a second copy would load as nothing. (The route this replaces was the `find-skills` skill shelling out to `npx skills add`, which needed a Node toolchain on PATH and wrote into whichever directory its `--agent` flag happened to map to — often one FastVibe cannot read. It now points at the pane.) The toolbar is **Search / Refresh / Skill Marketplace / Import**: *Import* has moved out of the ⋯ menu into a first-class button, and the hand-authoring *New* entry is gone.
- **Code blocks in replies read like the files they quote.** A fenced block now carries a line-number column and its language's file icon — the same marks the file preview and the project tree use. A one-line block draws no gutter, a `diff` block keeps the diff viewer's own numbering (read from the hunk header, not from counting rows), and a language with no icon draws nothing rather than a blank page. This also fixed a hidden layout bug: highlighted lines were a pixel taller than the plain-text fallback, so line numbers slid off the code the moment a grammar loaded.

### Improved

- **Proxy settings apply as you change them.** The pane no longer held a draft behind an **Apply** button, which meant nothing on screen was the network's real state until somebody pressed it. Every row writes the moment it changes — the switch and the selects immediately, the address on blur or Enter, so a half-typed `http://1` never becomes the route in effect on the way to the one you meant. A save that fails pulls the controls back to what is actually in effect and says so in a toast. Protocol, host and port have also collapsed into a single address (`http://host:port`, `socks5://[::1]:1080`; the port is optional), and a settings file written by an older build is folded into that address as it is read — an install that already routes through a proxy keeps doing so after the upgrade with nothing to re-enter.
- **Fewer update checks.** The background check now runs hourly instead of every ten minutes. At worst the badge names a release an hour older than it is; everything else is unchanged, because **Update now** already re-reads the feed whenever the notice on screen has gone stale — that, not the interval, is what kept an install from landing on a superseded version.

### Fixed

- **A conversation no longer flickers with overlapping turns.** Opening or switching to a chat now keeps the transcript hidden until the list's real row heights have been measured: the first frames used to lay rows out by estimate, and a turn taller than its estimate overlapped the one below it.
- **A maximized window is no longer shown at the wrong size.** Launching into a restored maximized window drew the small layout stretched over the large window, then re-laid it out; it now paints at full size before it becomes visible.
