### Improved

- **A folded run no longer fills the window.** Expanding the header a finished turn folds
  behind, a batch of tool calls, the earlier steps of a long run, or a long prompt opened in
  place now caps its body at 20rem — or 40% of the window height, whichever is smaller — and
  scrolls inside itself, so the answer the fold exists to leave on screen stays in view. The
  cap scales with Interface size. A single tool card keeps the bound its own output panel
  already has and gains no second one.
- **What is happening now is always on its own line.** A running tool used to be drawn *as*
  the batch line, so that one row alternated between "Read 3 files" and "Reading config.ts" —
  and the "Working" row appeared and vanished underneath it, in the same spot a status had
  already claimed. Finished calls now fold into the count and the call in flight stands on its
  own line below, joining the count once it returns. A thought being written does the same, so
  **Collapse thinking** (Settings → Preferences → Chat) only decides where a *finished*
  thought goes; its description now says exactly that.
