### Improved

- The project and Git branch pickers now fit the window. When the list is taller than the space above the composer, it scrolls instead of running off the screen.

### Fixed

- Switching the interface language now updates screens that are already open. The side pane renames its tabs immediately, and grouped tool rows redraw in the new language, so leaving Settings no longer leaves the previous language on screen until a reload.
- Prompt bubbles no longer show the image-resize note the engine appends after a photo, and the photo itself is unchanged.
