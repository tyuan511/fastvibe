### 新增

- **图片生成。** 全局侧栏新增「图片生成」工作台：输入提示词即可生成 1–4 张图片，可添加一张参考图用于改图。图片模型在「设置 → 供应商」中与聊天模型一同管理，支持 GPT Image、Gemini Image、Grok Image 三种协议，并可设置默认图片模型；每个图片会话保留提示词、参数与成图。对话也能生图：配置图片模型后，Agent 与子 Agent 获得 `generate_image` 工具，生成结果以图片网格呈现在会话中。
- 聊天支持渲染 Mermaid 图表。`mermaid` 代码块会按当前主题绘制成图，可切换源码、复制与查看原图；超长或尚未写完的块保持普通代码显示。
- 手机可直连本机。开启远程访问后，电脑会在局域网内广播直连地址，登录同一账号的手机可通过 Wi-Fi 直连，无需经过中转。

### 改进

- 连接会使用全部已配置的中转节点，而不是只用第一个：单个中转离线不再阻断连接，损坏的中转列表会被明确报错而不是半途失效。
- 后台压缩上下文（设置 → 对话）改为静默且不阻塞：空闲会话在后台准备摘要，不再弹出任何提示，完成后只在会话里出现普通的「已压缩上下文」分隔条，下一条消息也不会等待后台整理。
- 「远程访问」设置页现在聚焦账号连接：一个开关、电脑名称、传输状态、已连接设备与中转用量。原有的局域网密码与扫码配置已移除；同一网络里的手机改经账号连接的直连路径访问本机。
- 点击 Vivi 桌面宠物会打开它的对话；点击互动不再依赖任务通知开关，剩下的开关只控制任务通知。
- 插件入口从侧边栏移入「设置 → 插件」；旧的插件页会跳转到新位置。

### 修复

- 一轮回复的「文件变更」卡片不再随回复进行而不断长高，现在在最终回答结束后出现在工具折叠区之外。
- 调整模型选择菜单布局：模型与思考程度共用一个标题区，「管理模型」改为标题区内的紧凑按钮，不再是底部一整行。
