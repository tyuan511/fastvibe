### Fixed

- User messages in the main chat and agent side pane now collapse when they exceed two displayed lines, even below 500 characters. Expanded messages stay within half the chat reading area, with longer content scrolling inside the bubble.
- The nine-dot animation now appears only in the reply’s Working row. Conversations, projects, task lists and agent resources use circular running indicators again, while tools and retries use their regular spinners.
- The Working row now matches the spacing and text style of tool rows, and inline agent avatars are more compact.
