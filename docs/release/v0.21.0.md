### Added

- **Office documents are first-class.** Word, Excel and PowerPoint (`.docx` / `.xlsx` / `.pptx`) now render as actual pages — in the **Files** panel and inline in replies — instead of a screen of mojibake. The renderer ships inside the app: nothing to download, nothing to install, nothing added to your PATH, and **Settings → About** lists the bundled Office version.
- **The preview follows the file.** A local document stays live: edit it in Word, or let the agent rewrite it, and the page refreshes. Its toolbar has **Cite selection**, which puts the selected text — with a stable pointer back into the document — into the composer; **Use a static preview** falls back to a snapshot if the live view cannot start. A document on a connected SSH host still renders here, though the live view is this machine's own.
- **The agent edits those files through the same tool**, and a byte-exact snapshot is taken before it writes, so **Retry** on a turn restores the document instead of half-applying an edit. A document has no line diff, so a turn's change row says so and opens the file.
- `.doc` / `.xls` / `.ppt`, the ODF family and the macro-enabled variants are named as unsupported rather than mis-rendered, with **Open with system app** as the way out.
- **The file panel manages files now:** right-click for **New file**, **New folder**, **Rename** and **Delete**. Every action stays inside the project root and refuses `.git`, a rename never lands on a name that already exists, and a delete here moves to the Trash — on a remote host the dialog says plainly that it cannot be undone.
- **Real file-type icons** (vscode-icons, vendored into the app): the file tree, each turn's changed-file chips and the preview strip draw the language's own glyph, with the light artwork on light themes.
- **HTML written in a reply renders.** `<kbd>`, `<br/>`, `<details>` and centered badges appear as elements instead of as their own tags — through a whitelist, so a `<style>` block or a `<script>` cannot paint over the app itself.

### Performance

- Opening a long conversation costs about a third of what it did: one read and one parse of the transcript instead of three — 441–524 ms down to 146–166 ms on an 82 MB session — and switching chats no longer re-transpiles the extensions every time (~110 ms down to ~6 ms).
- **Screenshots stopped living in memory as text.** An image a tool returned is kept by reference, each picture is downscaled once when it arrives (3.8 MB down to 233 KB), and only the newest ones inside a 4 MB budget are re-attached to a request. The conversation that held 84 MB of heap now holds 6 MB, and its transcript carries no base64 at all. Older transcripts convert themselves as they open; the files on disk are untouched.
- **Streaming stopped replaying a tool call's arguments with every update.** A 100 KB file write used to push roughly 125 MB through the event bus, which a phone or a remote host on the other end could not keep up with; the same call is now about 2.5 MB across 84 events, and the final state is identical.
- The window appears sooner (the login shell's PATH is probed alongside startup rather than before it), and the interface asks for state, transcript and statistics once per burst instead of once per event.

### Improved

- A code fence inside a Markdown reply is colored in its own language (`html` inside `markdown` used to come out flat), and every diff — a tool's change, a fenced `diff`, the Git panel — is drawn by one renderer that reads real line numbers and wraps long lines instead of pushing the interesting half off-screen.
- One scrollbar everywhere: the conversation's own bar is drawn like every other bar in the app instead of reverting to the platform's boxy one.
- The todo list follows one rule in both places, so a superseded or abandoned plan closes in the composer tray *and* in **Conversation resources** rather than the two disagreeing about it.

### Fixed

- Chats no longer vanish from the sidebar. Two processes on one data directory (the installed app beside a `pnpm dev`) overwrote each other's conversation list; writes now merge what is already on disk, land atomically, and keep a copy of a catalog that cannot be read before replacing it.
- The terminal garbled Chinese and other non-ASCII text when FastVibe was started from Finder or the Dock, which hands it no locale at all and left every command it spawned running as US-ASCII. A UTF-8 `LC_CTYPE` is now set for the terminal, the agent's own commands and Git alike — and anything you set yourself is left exactly as it is.
- A run you stopped is no longer a red error bubble reading *This operation was aborted* in untranslated English. It was never a failure, and it now reads as an interruption.
- A file that cannot be opened says what happened in plain words, with a way out (its folder, another application), instead of printing `ENOENT: no such file or directory, stat '/Users/…'`.
- Git's branch, tag and HEAD marks scale with the interface font size instead of staying fixed beside text that grows.
