## Breaking changes

- **The decision engine (决策引擎 / Jev) is removed.** Browser and desktop work is now done by the main model stepping through the ordinary `browser_*` / `computer_*` tools, one action at a time. Settings → 决策引擎, the `browser_task` / `computer_task` / `batch_decide` tools and the **System One** API format are gone with it. A stored provider whose protocol was System One is dropped on load rather than repaired into a chat provider whose every request would fail; its key stays in the runtime env file, unreferenced and inert. Existing conversations and every other provider are unaffected.

## Improved

- A long conversation with hundreds of tool calls no longer gets slower per token while it streams: settled tool summaries are reused instead of rebuilt on every flush, and the turn rail measures itself only when the number of ticks changes.
- The git pane, the branch chip, the file tree and the resources panel now share one status poller per workspace instead of one timer each, and the diff re-reads only when the status actually changed.
- Office previews show the static render immediately while the live server starts, so a document is never a blank frame for the first second or two.
- Provider settings are one accordion on every window size, with the name editable in place, drag-to-reorder for providers and models, and a per-model check on each row.
- A sub-agent task graph in the transcript starts as one line — state, progress bar, 取消全部 and 最大化 all stay on it — and opens on a click.
- A thinking block that carries no text takes no row once it has ended, so a reply no longer shows an empty 「思考」 box between real thoughts.

## Fixed

- Opening 使用统计 on a large history no longer re-parses every transcript on each launch (294 MB: about a second down to a few milliseconds on the second launch).
