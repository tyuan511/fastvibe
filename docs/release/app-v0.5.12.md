### Improved

- Refined the native Android and iOS interfaces across sign-in, computers, connection progress, conversations, settings, and action sheets, with coordinated light and dark appearances.
- Improved conversation readability with clearer thinking and tool states, compaction details, elapsed times, file diffs, and queued messages. iOS now uses live backdrop blur and more consistent Chinese typography, message widths, and line spacing.

### Fixed

- Fixed Android conversation rows and messages scrolling through the header. Headers now occupy a separate area, keeping titles, connection status, and navigation controls readable while scrolling.
- Fixed the latest iOS reply being covered by a growing multiline input. Corrected filter-sheet overflow with many projects and excess spacing in Android input and selection sheets.
- Improved iOS command result handling and compatibility with older computer-list metadata.
