### 修复

- 主聊天与侧边 Agent 聊天中的用户消息超过实际显示的两行时会自动折叠，不再要求超过 500 字。展开后正文最高为聊天阅读区的一半，更长内容在气泡内滚动。
- 九点动画仅用于回复底部的「工作中」一行。会话、项目、任务清单与 Agent 资源恢复圆形运行标记，工具和重试恢复普通转圈图标。
- 「工作中」一行的间距与文字样式和工具行保持一致，行内 Agent 头像更加紧凑。
