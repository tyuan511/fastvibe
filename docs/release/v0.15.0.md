### Added

- **Phone connections for SSH hosts.** In Settings → SSH hosts, edit a host and turn on **Allow phone connections**: set a password and a fixed port (and, optionally, a public address) and the host's Agent restarts once to accept connections from the FastVibe mobile app directly, without SSH. The phone talks to the same Agent, so it sees the same chats and models. A host that allows it shows a QR code icon in its row — hover it and scan it with the phone. The pane notes what is yours to arrange: opening the port in the server's firewall and cloud security group, and putting https in front, since an iPhone refuses plain `http://` outside the local network.
- **Start Agent without a project.** A host's **More** menu has a new **Start Agent**, which sets up and starts the Agent on that machine through the same steps a new project uses, with live progress for the download and deploy. Adding a project later finds it already running.

### Improved

- An SSH host's **Test connection** and **Stop remote Agent** now sit in the **More** menu instead of taking two buttons of the row.
- When the remote Agent fails to start, the message says why (a port already in use, an Agent too old to accept phone connections) instead of "exit 1".

### Fixed

- **A phone connected to a remote Agent no longer shows a spinner and then nothing.** Replies in chats the desktop was not showing were dropped before they reached the phone, so a run that finished on the server looked like it never answered. They now stream through.
