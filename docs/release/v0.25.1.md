### Breaking changes

- The first launch upgrades the local application database. Earlier FastVibe versions cannot open the upgraded data directory. If you may need to roll back, back up the complete application data directory before upgrading.

### Added

- Vivi now has her own persistent memory, separate from the optional memory used by regular chats. She can remember explicit requests and learn from newly completed work, then refer to those notes in later conversations. Existing conversation history is not scanned retroactively.
- Vivi brings questions from her own conversations and their plugins into one panel above the composer. Switch between pending questions without losing typed answers, and edit longer responses inline. Reloading the interface restores requests that the running engine is still waiting on.
- After an application restart, Vivi checks interrupted work and continues unfinished work in its original conversation after reviewing existing files and results. User-stopped work stays paused; failed or blocked results and unanswered questions require attention rather than automatic execution.

### Improved

- Vivi chat now keeps your messages, attachments, replies, milestones and final results in a dedicated conversation feed. Sending responds immediately with your message and a quiet processing indicator; progress questions are answered in the same chat. Failed sends keep your draft and attachments available.
- Describe which local project you want Vivi to use, and she can start work in that project with its project instructions and folders. Work without a project gets a separate, persistent workspace for each conversation. Follow-ups continue in the existing workspace.
- Vivi conversation cards now show recent reply previews, status and project context, making it easier to find and reopen ongoing work.
- Vivi and regular chat memory share a forgetting policy: unused notes expire after 30 days by default, while meaningful reuse can extend retention up to 360 unused days. Explicitly saved notes follow the same policy.
- Files produced during a reply can be opened directly from shortcuts beside the collapsed process row. The resource panel no longer repeats a separate recent-output list.
- Refined the thinking-effort slider with smoother visual feedback as you adjust the level.

### Fixed

- Fixed missed or stale plugin questions after switching views or reloading the interface. Answers stay attached to the correct request, and a failed response preserves the form for retry.
- Strengthened Vivi stop and recovery behavior so late progress updates and recovery actions cannot restart work you explicitly stopped.
