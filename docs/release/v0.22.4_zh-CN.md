### 新增

- **技能调用不再刷屏。** `/skill:office 帮我写个周报` 过去会把整份 `SKILL.md` 落进转写——几千字不是你写的，还顺手变成了会话标题和侧栏预览。现在它只显示一枚「技能」标记，旁边是你自己那句话；编辑、复制或重试这条消息仍然会带上技能，手机端呈现一致。
- **新增「折叠思考内容」**（设置 → 偏好设置 → 对话，默认关闭）：思考并入它所在的工具行，汇总成「已思考 N 次」。正在写的思考在折叠行里保留动画和实时预览。
- **多文件夹项目会把每个文件夹告诉智能体。** 第二个仓库的 `AGENTS.md` 和技能会被列出来，让它在这个文件夹真有活要干时自己去读；`@` 文件搜索覆盖项目的所有文件夹；工作目录、路径和 git 状态只在真的变化时刷新。
- **侧栏悬停会话卡片显示累计用量**——轮次、累计 Token 和输出 Token——直接从转写读取，看一眼不会额外起一个会话。
- **设置 → MCP 工具里每个服务器都有独立的重新连接按钮。** 只断它那一个、重连它一个，并让所有会话重载拿到新工具列表，别的服务器不受影响。

### 改进

- **提交只剩一条路径。** Git 面板和聊天顶部都是：暂存整个仓库、草稿为空时自动写提交信息、提交，只有你要求时才推送。「提交（修订上次提交）」和「提交并同步」去掉了；生成提交信息时显示转圈和占位文案，提交成功而推送失败会单独报告，不再看起来像什么都没发生。
- **只带文件、不带文字的消息会保留你的原话。** 过去它发给模型的是「请查看附件」，气泡里却是文件名，重开聊天就等于改写了你自己的消息。
- **回复里的图片按图片显示**，不再是一枚 24px 的小块；缩略图和查看器共用同一个 lightbox。
- **设置 → 关于** 删掉了和其他面板重复的条目，模型索引与它的数量现在待在属于它的位置。
- **长期记忆更省。** 读取规则留在系统提示里，摘要改以可复用的上下文快照传递，一次整合不会再毁掉请求前缀。

### 修复

- **失败的一轮回复变成一句结论 + 可展开的详情**，不再是一整块红气泡。像 `429: {"message":…,"type":"insufficient_quota"}` 这种供应商报错、以及结尾是一条裸文件路径的 SDK 配置错误，会被拆成首句结论加每因一行；这样的长路径再也不会把会话栏撑得横向滚动。供应商原文一键可复制。
- **模型刷空白不再占满一屏。** 有时它会交出一大段 `<br>` 或由不可见字符组成的行，现在这类内容会被收敛，没有可读内容的部分不占行。
- **安装版打不开内置终端**（`posix_spawnp failed`）。打包后 pty 的辅助程序去错了目录；开发态没有这层打包，所以只有装过的用户会遇到。
- **模型的上下文窗口和价格可能毫无征兆地变化。** 公开模型目录把同一个模型列在每个分销商下面、数值互相冲突，而过去胜出的是恰好排在最前那条。现在排序是确定的，你没手动调过的已保存模型会重新读取当前数值——已经存下错误价格的安装也会跟着修正。
- **会话标题、`/handoff`、AI 提交信息和模型自检会静默失败**，对象是那些拒绝「关闭思考」参数的模型；现在这类请求会换成端点接受的形式重发。
- **启动不再等 MCP 服务器。** 它们在后台连接，第一次可用通常早 0.5–1.5 秒（服务器很慢时更多），第一条提示只等很短的一点工具加载时间。
- **模型切换那一行不再截断**它本来要说清楚的模型名。
