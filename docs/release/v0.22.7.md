### Improved

- **Commit messages generated by AI are always English.** The subject is written in English no matter what AI 偏好语言 is set to, because it is a line of repository history that `git log`, CI and teammates read — it used to follow the chat language and came out in Chinese. Conventional-commit prefixes (`feat:`, `fix:` …), the single-line / ≤72-character / no-trailing-period rules are unchanged.
- **A turn's changed-files card is much more compact.** One header line (count, line totals, expand arrow, 查看变更), then one row per file with its own file icon, the file name, and the directory muted behind it. The list is five rows tall and scrolls inside the card instead of pushing the reply off screen; the nested "show N more files / collapse" step is gone, since the header already collapses the whole card.
- **Attached images use one thumbnail size.** A pasted screenshot is an 80px square in the composer and in a message alike, instead of a bounded full-width picture that filled the first screen of a chat. The whole image is one click away in the lightbox.

### Fixed

- **Opening a fold no longer flashes a horizontal scrollbar.** Our scrollbar takes 11px of layout, so a body that crossed its height cap lost that width from the inside, every row re-laid out narrower, and content on the edge overflowed sideways. The gutter is now reserved whether or not the bar is present, and a fold body never scrolls sideways at all.
- **An expanded fold is capped at half the reading area, with one scrollbar.** The cap used to measure the window rather than the transcript area, and a tool batch inside 用时 was capped as well — a scrollbar inside a scrollbar. The cap is now half of the real reading height, and only the outermost fold scrolls while an inner body contributes its full height.
- **The 用时 fold no longer pushes its own answer off screen** when it holds a long run, and a batch is still bounded while the run is live, before any fold exists above it.
