### Fixed

- **FastVibe v0.19.0 could not start.** It failed on launch with `Cannot find package 'cross-spawn'`: the packaged app was missing several runtime dependencies of the agent engine. This release goes back to the dependencies v0.18.1 shipped with, and the app opens normally again.

**If v0.19.0 is installed and will not open, the in-app updater cannot help, because it runs inside the app that will not start. Download the installer for your platform from this release and install it over the existing app.** Your settings and conversations are not touched.

**Full Changelog**: https://github.com/tyuan511/fastvibe/compare/v0.19.0...v0.19.1
