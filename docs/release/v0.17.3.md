### Added

- Computers with LAN access enabled now advertise themselves on the local network, so the phone client can find nearby FastVibe machines. Set the computer name in Settings → Remote Access to choose how it appears.

### Improved

- Connection QR codes now include the computer name for LAN, tunnel and SSH phone connections. Scanning fills in a suggested connection name while preserving a name you have already edited.
- Startup keeps the loading screen visible until the saved workspace and conversation have been restored. Slow launches offer a reload control, and startup failures leave recovery controls accessible.

### Fixed

- Delegated tasks no longer stop just because they have read a large amount of context or reached a cumulative token or turn count. Tasks still obey their execution deadline and retry limit, and usage remains available for inspection.
