### Added

- **A skill you invoke is no longer a wall of instructions.** `/skill:office 帮我写个周报` used to land in the transcript as the whole `SKILL.md` — several thousand words nobody typed, which also became the chat's title and its sidebar preview. It now shows a small 技能 badge beside your own words; editing, copying or retrying that message still sends the skill, and the phone renders it the same way.
- **A 折叠思考内容 switch** (Settings → Preferences → Chat, off by default) folds a thought into the tool line it sits in, counted as "thought N times". A thought still being written keeps its animation and its live preview inside the folded line.
- **Multi-folder projects tell the agent about every folder.** A second repository's `AGENTS.md` and skills are named so the agent can read them when its work reaches that folder, `@` file search now covers all of the project's folders, and the working directory, paths and git status are refreshed only when they actually change.
- **Hovering a conversation in the sidebar shows its cumulative usage** — rounds, total and output tokens — read from the transcript, so it costs no agent session to look.
- **Each MCP server row in Settings has its own reconnect button.** It drops and re-connects that one server and reloads every chat to pick up its tools; the other servers are untouched.

### Improved

- **Commit is one path now.** The Git pane and the chat header both stage the repository, write a message when your draft is empty, commit, and push only if you asked. 提交（修订上次提交） and 提交并同步 are gone; generating a message shows a spinner and a placeholder, and a push that fails after a good commit is reported on its own instead of looking like nothing happened.
- **A message with only files attached keeps your words.** It used to send "请查看附件" to the model while the bubble listed the file names, so re-opening the chat rewrote your own message.
- **Images in a reply are shown as pictures, not as 24px chips**, and both the chip and the picture open the shared viewer.
- **Settings → About** dropped the rows that duplicated other panes and now reports the models index and its counts where they belong.
- **Long-term memory costs less.** Its rules stay in the prompt while the summary travels as a reusable context snapshot, so the request prefix survives a consolidation instead of being thrown away every turn.

### Fixed

- **A failed reply is one sentence and a details drawer, not a red wall.** Provider errors like `429: {"message":…,"type":"insufficient_quota"}` and SDK setup messages ending in a bare file path are split into a headline plus one line per cause, and such a path no longer forces the conversation column to scroll sideways. The provider's original wording is always one click to copy.
- **A reply padded with blank content no longer takes a screen.** Models sometimes emit dozens of `<br>`s or lines of invisible characters; those are shortened, and a part with nothing to read takes no row.
- **The installed build could not open the built-in terminal** (`posix_spawnp failed`). The bundled pty helper looked for itself in the wrong directory inside the packaged app; the in-development copy never hit it, which is why only installed builds failed.
- **A model's context window and price could change with no warning.** The public model list carries one model under every reseller that offers it, with numbers that disagree, and the winner used to be whichever entry happened to come first. Ordering is now deterministic, and saved models that you did not edit re-read the current values — including for installs that had already stored a wrong price.
- **Chat titles, `/handoff`, AI commit messages and the model self-check could fail silently** on models that reject a "no thinking" parameter; the request is now resent in a form the endpoint accepts.
- **Startup no longer waits on your MCP servers.** They connect in the background, so the first chat is ready 0.5–1.5 s sooner (longer when a server was slow), and the first prompt waits only a moment for the tools it needs.
- **The model-switch line no longer truncates the model name** it exists to show.
