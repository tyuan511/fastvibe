### Added

- Image workbench: an options picker on the composer lets you choose model, size, and quality per generation; generated results live in per-session galleries with a reference action on each image, so picking one feeds it straight into the next prompt.

### Improved

- Agent tool rows in the transcript now fold `list_agents` into batched tool runs while running waits and team changes keep their dedicated rows.

### Fixed

- Agent Team followups: the followup message is now the sole source of the new turn's task; the removed `task` parameter no longer creates turns whose brief differs from what was actually sent.
- LAN discovery: when a VPN/tunnel owns the default route, a failed multicast send used to stop LAN announcements until restart. Discovery announcements now retry with backoff, so the phone's LAN hint recovers on its own.
