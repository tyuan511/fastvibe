### 新增

- **Review 模式。** 新增专用的代码审查，由一个内置审查角色执行，使用单独的审查模型和推理强度。可以从 Git 面板、审查对话框启动，也可以在输入框发送 `/review <审查重点>`。每次审查都基于所选变更的不可变快照（工作区、已暂存、分支或指定提交），报告描述的一定是它真正读到的代码。结果在独立侧栏打开：按严重程度列出问题，每条包含文件位置、代码片段、触发条件、实际影响、证据和修复建议。聊天里是一张精简卡片，每个问题一行并显示优先级，右侧的**全部修复**会向同一会话发送一条普通提示词，逐项处理所有问题。
- **新会话的独立 Worktree。** 新会话的项目行新增「使用独立 Worktree」复选框，默认不勾选，选择 Git 项目后可启用。首次发送时创建该工作区并在其中执行任务；创建失败会停止发送并恢复你的草稿，重试会复用同一个 Worktree，不会重复创建。
- **刷新模型列表。** 设置 → 模型与默认新增「刷新模型列表」，用于其他程序在 FastVibe 运行期间改写供应商配置的情况。它会重新读取当前模式的配置，并刷新供应商行和模型菜单。配置加载失败会报错，而不是把列表清空。
- **内置 Mermaid 指引。** 随包提供一个图表技能，覆盖语法与布局选择，画图请求无需额外安装也能得到一致的结果。
- **浏览器：限定范围的快照与原生输入。** 页面快照可以只针对某个元素，引用更严格并支持开放的 shadow DOM；输入、点击和组合键在 Chrome 与内嵌浏览器中走同一条原生输入路径。

### 改进

- Markdown 中的图片直接渲染在正文里，不再是文件名标签，保持宽高比并限制最大尺寸。图片查看器支持以光标为中心滚轮缩放，点击 Mermaid 图表会全屏打开。

### 修复

- **Agent Team 不再撑爆上下文。** `list_agents`、`wait_agent` 和 `spawn_agent` 过去会返回每个线程的完整系统提示词、任务和最后一条完整回复，反复查询会不断重发数 KB 的内容，可能耗尽会话上下文。现在只返回每个线程的精简摘要，团队没有变化时重复查询只回一行提示，完整内容只留在侧栏。
- 工具行的标签在只有一行时也可能出现滚动条；现在其测量高度与实际绘制一致。
- Vivi 过去每次启动都会重新提醒未解决的问题和失败结果。现在已提醒过的条目会跨重启记住，旧条目保持安静，新条目仍会提醒一次。
- 远程客户端现在可以打开图片工作台：这些方法在策略上已放行，但一直没有归属到任何能力，因此会被拒绝。
