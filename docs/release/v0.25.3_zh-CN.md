## 改进

- 持续目标现在会明确核验完成条件和重复阻塞，并能在请求重试、上下文压缩、暂停及应用重启后安全延续。可设置目标的 Token 总预算，统计范围包括委派的智能体，不计缓存读取；也可由运维配置最大预算，为目标设置默认值并限制预算上限。目标耗时现在包含工具执行时间。
- Agent Team 的内置 `explorer` 和 `worker` 角色现在在所有角色范围下均可使用；同名的用户或项目角色仍可覆盖内置定义。
