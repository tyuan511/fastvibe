### Added

- **Image generation.** A new Image generation workbench in the sidebar turns a prompt into 1–4 images, with one reference image for edits. Image models are managed in Settings → Providers next to chat models — GPT Image, Gemini Image and Grok Image protocols, plus a default image model — and every image session keeps its prompts, parameters and finished pictures. Chats can generate too: once an image model is configured, agents and subagents gain a `generate_image` tool, and results render as an image grid in the conversation.
- Chat now renders Mermaid diagrams. `mermaid` code blocks are drawn as diagrams that follow the app theme, with source, copy and open-image controls; oversized or half-streamed blocks stay as plain code.
- Direct local connections for phones. While remote access is on, the computer advertises its direct addresses on the local network, so a phone signed in to the same account can connect over Wi-Fi without going through the relay.

### Improved

- Connections use every configured relay node instead of only the first one: one relay being offline no longer blocks connecting, and a broken relay list is reported instead of silently half-working.
- Background context compaction (Settings → Chat) is silent and non-blocking: idle sessions prepare the summary in the background without toast interruptions, the completed summary appears as the ordinary "Compacted context" divider, and the next message is never held up waiting for it.
- The Remote access pane now centers on the account connection — one switch, the computer name, transport status, connected devices and relay usage. The separate LAN-password and QR-code setup is gone; phones on your network reach this computer through the account connection's direct path instead.
- Clicking the Vivi desktop pet opens its chat, and click interactions no longer depend on the task-notification switch. The remaining switch governs task notifications only.
- Plugins moved from the sidebar into Settings → Extensions; the old plugins page redirects there.

### Fixed

- The per-turn changed-files card no longer grows while a reply streams; it now appears after the final answer, outside the tool fold.
- Refined the model-selection menu layout: the model picker and reasoning level share one header, and "Manage models" is a compact button in that header instead of a bottom row.
