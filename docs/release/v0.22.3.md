## Added

- **A Dock badge on macOS counts the chats that finished while you were away.** Opening one, or deleting or unbinding it, lowers the number; the count survives a restart. It is independent of system notifications, and clicking back into the app does not wipe it.

## Fixed

- **模型管理 is a single column of providers again**, with each provider's configuration and model list opening in place instead of a list-beside-detail split. Providers and their models can be dragged to reorder (saved by id), and a provider's name is edited in the row itself.
- **输出速度 now describes one request.** It was the turn's remaining output divided by every round trip in the turn, so a turn with four requests reported an average of four and a long tool run in the middle read as the model slowing down. It is now the latest completed request's own output over its own duration — first-token wait included, tool waits excluded — and an untimed request shows `—` instead of borrowing an older request's number. The row's hint says so.
