## Improved

- Persistent goals now have explicit completion and blocker checks, and continue safely across retries, compaction, pauses and app restarts. You can set a total token budget; usage includes delegated agents, while cache reads are excluded. An optional operator-configured maximum can set the default and cap goal budgets. Goal elapsed time includes tool work.
- The built-in `explorer` and `worker` Agent Team roles are now available with every role scope. User and project role definitions can still override a built-in role with the same name.
