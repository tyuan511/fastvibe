### 新增

- **Office 文档正式支持。** Word、Excel、PowerPoint（`.docx` / `.xlsx` / `.pptx`）现在渲染成真正的版面——在**文件**面板里、也在回复里直接画出——不再是一屏乱码。渲染器随安装包发布：不用下载、不用安装、不改动你的 PATH，**设置 → 关于** 里能看到内置的 Office 版本。
- **预览跟着文件走。** 本机文档是实时的：在 Word 里改、或者让智能体改写，页面自己刷新。预览标题栏有**引用选中内容**，把选中的文字连同一段回指文档的稳定位置放进输入框；实时预览起不来时可以用**使用静态预览**回到快照。远程主机上的文档照样能在这台电脑渲染，只是实时预览属于本机。
- **智能体用同一个工具编辑这些文件**，动手写之前先留一份逐字节的快照，所以**重试**某一轮会把文档还原，而不是留下半份改动。文档没有逐行 diff，每轮的改动记录会这么写明，点开是文档本身。
- `.doc` / `.xls` / `.ppt`、ODF 系列和带宏的变体直接说明不支持，而不是画错给你看，并给出**用系统应用打开**这条出路。
- **文件面板能管文件了：** 右键可**新建文件**、**新建文件夹**、**重命名**、**删除**。每个操作都限在项目目录内、且拒绝碰 `.git`，重命名绝不覆盖已经存在的名字；在本机删除是移到废纸篓，远程主机会明说无法恢复。
- **真正的文件类型图标**（内置的 vscode-icons）：文件树、每轮的改动文件列表、预览条都画出该语言自己的图形，浅色主题换用浅色那套 artwork。
- **回复里的 HTML 会渲染。** `<kbd>`、`<br/>`、`<details>` 和居中的徽章按元素画出来，不再显示标签本身——走的是白名单，所以一段 `<style>` 或 `<script>` 盖不到应用界面上。

### 性能

- 打开长对话的开销大约降到原来的三分之一：转写只读一遍、只解析一次（以前是三遍）——一个 82 MB 的会话从 441–524 ms 降到 146–166 ms；切换对话也不再每次重新转译扩展（~110 ms 降到 ~6 ms）。
- **截图不再以文字的形式占着内存。** 工具返回的图片只存引用，图片到达时缩一次（3.8 MB 降到 233 KB），每次请求只把 4 MB 预算内最新的那几张读回去。原先占 84 MB 常驻内存的那个会话现在占 6 MB，转写里也不再带 base64。旧转写在打开时于内存里转换，磁盘上的文件不动。
- **流式输出不再把工具调用的参数整份重播。** 写一个 100 KB 的文件过去要挤过约 125 MB 的事件总线，手机或远程端根本跟不上；同一次调用现在是 84 个事件、约 2.5 MB，最终状态一模一样。
- 窗口出现得更早（登录 shell 的 PATH 改在启动的同时探测，不再挡在启动前面），界面在一串事件里只索取一次状态、转写和统计，而不是每条事件一次。

### 改进

- Markdown 回复里的代码块按它自己的语言上色（markdown 代码块里嵌的 html 代码块以前是平涂的），所有 diff——工具改动、`diff` 代码块、变更视图——由同一个渲染器绘制：行号从 diff 本身读出来，长行换行而不是把有意思的那半截推到屏幕外。
- 滚动条统一成一根：聊天区那根不再退回系统自带的方形样式，和应用里其余的画得一样。
- 任务清单在两处用同一条规则判断，于是一份已经被取代或放弃的计划，会在输入框上方**和**「会话资源」里一起收起，不再两边说法不一致。

### 修复

- 侧栏不再丢会话。同一个数据目录上可以同时跑两个进程（安装版旁边开一个 `pnpm dev`），它们会互相覆盖对话列表；现在落盘前会吸收磁盘上已有的内容、写入是原子的，读不出来的目录在被替换前先留一份副本。
- 从 Finder 或 Dock 启动 FastVibe 时，终端会把中文和其他非 ASCII 文字弄成乱码：这种启动方式根本不给它 locale，于是它派生的每条命令都跑在 US-ASCII 下。现在终端、智能体自己的命令、Git 都会拿到一个 UTF-8 的 `LC_CTYPE`——你已经设置过的值一概不动。
- 被你停掉的运行不再是一个红色错误气泡、里面一句没翻译的英文 *This operation was aborted*。它从来不是失败，现在也按中断来显示。
- 打不开的文件用人话说清发生了什么，并给一条出路（它所在的文件夹、换个应用），不再打印 `ENOENT: no such file or directory, stat '/Users/…'`。
- Git 的分支、标签和 HEAD 标记跟着界面字号缩放，不再在文字变大的时候保持固定大小。
